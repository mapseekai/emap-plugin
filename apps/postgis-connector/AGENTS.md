# postgis-connector

Read ../../AGENTS.md. This is a private desktop application, not an independently published map plugin.
Production uses the small native-service executable. Preserve the public PostGIS HTTP/WKB contract and compare it against the public /server export in tests. Never import host/plugin private implementation paths.
The browser can only pair/query. Configuration and approval are available ONLY over parent-child stdio IPC.
Never expose an auto-approve flag, database credentials, management HTTP routes, permissive CORS or shell execution.
Keep tokens short lived and origin/connection scoped. Revoke active work when consent is withdrawn.
No keychain plaintext fallback. Native renderer loads bundled assets only. No remote IPC capability.
Tests use disposable fixtures, never saved user connections. No installer execution or system registration without consent.
