# 界面与 EC 标志微调（2026-09-19）

## 本轮范围

保留已开发的单页纵向界面：页头、待授权请求、数据库连接、添加/重新配置表单、站点授权、当前会话、退出。
不增加侧栏、搜索、登录、左右分栏、多数据库类型或新的弹窗。

参考 emap 已实现的 Mapseek 主题：主色 `oklch(0.6270 0.1940 149)`，细边框、直角、无装饰阴影、紧凑控件。
仅复制相关颜色语义的轻量 CSS fallback；不引入宿主私有模块、组件库、在线字体或额外运行时。
标题改为 `emap Connector`，EC 标志 44 × 32 CSS px，常用控件最小高度 32 px；主机与数据库信息使用系统等宽字体。

## 标志资源

`assets/ec-mark.svg` 按已确认的蓝/青/绿融合 EC 方案做轻量矢量适配（非原 PNG 原样嵌入），移除旧圆点标志。
矢量源 2691 字节；页头与 favicon 共享一个资源，不把原始大图嵌入页面。
`npm run icons:build` 从同一源生成桌面 ICO、ICNS、PNG 和 macOS 单色托盘图标。
macOS 托盘使用 template 模式，Windows/Linux 使用全彩默认应用图标；源图自带安全留白。
`npm run package:icons` 检查源图小于 4 KiB、PNG RGBA/尺寸、图标总预算及应用图标与源图的一致性。

## 微调的交互

打开表单时更新 `aria-expanded`；取消/保存后清空密码并将焦点返回添加按钮。
测试成功使用成功状态，不再显示成错误告警。凭据加载状态显示“就绪”，不冒充已验证的数据库连接。
完整站点来源、配对编号、只读权限提示、记住授权与撤销按钮仍保留。

## 验证

`npm run test:ui` 在 Chrome 中运行实际 HTML/CSS/TypeScript，并用只读 Tauri IPC 测试数据进行界面检查。
覆盖单页结构、标志尺寸、表单开关、密码清除、焦点恢复、刷新保留输入和授权选择、长文本转义以及 400/620/1100px 无横向溢出。
截图和报告位于 `test-results/ui/`；截图是代码渲染的测试状态，不是设计效果图，也不是用户业务数据库。
原生授权点击、系统安装及三平台真实外观仍需对应平台验收。
后端源文件 hash 对照确认数据库查询、授权服务和原有插件代码未发生变更。
